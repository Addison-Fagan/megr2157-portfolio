## Objective
The objective of this project is to dimension and size a structural bar using axial deflection modeling and parametric design principles. By linking CAD dimensions directly to design parameters, the structural geometry will dynamically update based on analytical governing equations. Additionally, this assignment introduces Finite Element Analysis (FEA) to evaluate stress and deformation under load. Comparing and contrasting the analytical deflection calculations with the computational FEA results will validate the structural behavior and highlight the differences between theoretical mechanics and numerical simulations.
